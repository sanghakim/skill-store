# Document Templates

## Report Template (보고서)

```
# [보고서 제목]

- 작성일: YYYY-MM-DD
- 작성자: [이름] / [부서]
- 버전: 1.0

## 1. 개요
[프로젝트/주제 배경 및 목적]

## 2. 현황 분석
[데이터 기반 현황 설명]

## 3. 핵심 발견사항
- 발견사항 1
- 발견사항 2

## 4. 결론 및 제언
[종합 결론과 향후 제안]
```

## Proposal Template (기획서)

```
# [기획서 제목]

- 작성일: YYYY-MM-DD
- 작성자: [이름] / [부서]

## 1. 배경 및 필요성
[왜 이 프로젝트가 필요한가]

## 2. 목표
- 정량적 목표
- 정성적 목표

## 3. 실행 계획
| 단계 | 내용 | 기간 | 담당 |
|------|------|------|------|
| 1    |      |      |      |

## 4. 예상 효과
[기대되는 성과와 ROI]

## 5. 리스크 및 대응 방안
[예상 리스크와 mitigation]
```

## Meeting Minutes Template (회의록)

```
# 회의록: [회의 주제]

- 일시: YYYY-MM-DD HH:MM
- 장소: [장소]
- 참석자: [참석자 목록]

## 주요 논의사항
1. [안건 1]
2. [안건 2]

## 결정사항
- [결정 1]

## Action Items
| 담당자 | 항목 | 기한 |
|--------|------|------|
|        |      |      |

## 다음 회의
- 일시: YYYY-MM-DD
- 안건: [예정 안건]
```
