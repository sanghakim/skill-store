Core Innovation

Agentic Loop:
자율 품질 보장 메커니즘

AI가 스스로 계획하고, 실행하고, 검증하는 반복 루프를 통해 사람의 검수 없이 95%+ 정확도를 달성합니다.

User Input
→
Plan
Planner Agent
→
Execute
Executor + Skills
→
Review
Reviewer Agent
→
PASS → Output FAIL → Re-plan

Plan (계획)

복잡한 요청을 하위 작업으로 분해하고 최적의 에이전트+스킬 조합을 결정합니다.

Execute (실행)

병렬 처리가 가능한 작업은 동시에 실행하여 속도를 극대화합니다.

Review (검증)

결과물의 정확성, 완성도, 톤을 자동 검증하고 미달 시 재실행합니다.

Competitive Edge

기존 AI 도구 vs SkillForge

비교 항목 기존 AI 챗봇 현재 SkillForge 제안
처리 방식 1명의 AI가 순차 처리 전문 AI 5명이 역할 분담 + 병렬 처리
품질 보장 사람이 매번 검수 Agentic Loop 자동 검증 (95%+ 정확도)
기억력 대화 끝나면 모든 맥락 소실 3계층 메모리로 사용자 패턴 학습
확장성 기능 고정, 개발팀만 수정 가능 Skill Store로 누구나 무한 확장
재사용성 좋은 프롬프트도 1회성 스킬로 패키징하여 팀/조직 공유
복잡한 업무 여러 번 수동 분할 요청 자동 분해 → 병렬 실행 → 통합 출력

Intelligence

3계층 메모리:
쓸수록 똑똑해지는 AI

Working Memory

SESSION • Redis

현재 대화의 맥락과 실행 중인 에이전트 상태를 실시간으로 관리합니다.

  • 대화 메시지 버퍼
  • 활성 에이전트 상태
  • 스킬 실행 스택
  • 토큰 예산 관리

Episodic Memory

PERSISTENT • PostgreSQL

과거 대화 이력과 작업 패턴을 저장하여 반복 학습합니다.

  • 세션 요약 로그
  • 작업 성공/실패 이력
  • 스킬 사용 통계
  • 자주 하는 업무 패턴

Semantic Memory

PERMANENT • Vector DB

장기적인 지식과 사용자 선호를 영구 저장하여 개인화합니다.

  • 사용자 스타일/선호
  • 도메인 전문 지식
  • 조직 템플릿
  • RAG 기반 검색

💡 사용 예시: "지난번처럼 해줘" → Episodic Memory에서 이전 작업 패턴을 검색하여 동일한 스타일로 자동 적용
